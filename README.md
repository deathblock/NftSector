# NftSector

A simple NftSector Service for Decentralized Governance.

NftSector is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- A simple NftSector Service for Decentralized Governance

## Key Features

- A simple NftSector Service for Decentralized Governance

## Technology Stack

- javascript
- javascript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftSector.git`
2. `cd NftSector`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure NftSector, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
